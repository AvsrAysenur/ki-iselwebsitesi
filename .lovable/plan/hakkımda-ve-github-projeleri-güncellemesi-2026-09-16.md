# Hakkımda ve GitHub Projeleri Güncellemesi

## Yapılacaklar
- Üst menüdeki “Hakkımda” bağlantısını doğru bölüme bağlayarak tıklandığında ilgili alana kaydırılmasını sağlamak.
- Ana tanıtım ve Hakkımda metinlerini Ayşenur’un ağzından, birinci tekil şahısla yeniden düzenlemek.
- “Uzmanlaşmış” ifadesini “kendimi geliştirmeye çalışan” şeklinde değiştirmek; Türkçe yazım, noktalama ve alan adlarındaki hataları düzeltmek.
- GitHub hesabındaki güncel herkese açık depoları mevcut proje kartlarıyla karşılaştırmak; yalnızca eksik projeleri README bilgileri, teknolojileri ve bağlantılarıyla eklemek.
- Menü bağlantısını, yeni kartları ve genişleyen proje ayrıntılarını masaüstü ile mobil görünümde kontrol etmek.

## Teknik Notlar
- Hakkımda bölümüne menü bağlantısıyla eşleşen sabit bir bölüm kimliği eklenecek.
- Proje verileri mevcut kart yapısına uygun tutulacak; GitHub’da bulunmayan bilgi uydurulmayacak.
- GitHub README görselleri güvenilir ve doğrudan erişilebilir durumdaysa kartlarda kullanılacak; aksi halde mevcut görsel yaklaşımı korunacak.
