# GitHub Projelerini Otomatik Gösterme

## Yapılacaklar
- GitHub hesabındaki herkese açık depoları site açıldığında otomatik olarak almak.
- Mevcut ayrıntılı proje kartlarını korumak ve aynı depoların iki kez görünmesini engellemek.
- GitHub’dan yeni eklenen depoları otomatik olarak proje listesine eklemek.
- Her GitHub projesinin kartında doğrudan görünen bir “GitHub” bağlantısı göstermek.
- Yüklenme ve GitHub’a geçici olarak ulaşılamama durumlarında mevcut proje kartlarını göstermeye devam etmek.
- Masaüstü ve telefon görünümünde listeyi ve bağlantıları doğrulamak.

## Teknik Notlar
- Herkese açık GitHub verileri doğrudan GitHub API üzerinden okunacak; giriş gerekmeyecek.
- Yeni depolar için açıklama, dil, güncellenme yılı ve GitHub’ın sosyal önizleme görseli kullanılacak.
- Yeni depolar otomatik gelir; ayrıntılı özel açıklamalar ve özel görseller mevcut yerel proje kartlarında korunur.
